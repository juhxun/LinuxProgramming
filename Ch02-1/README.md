# 실습과제 1

## 리눅스 명령어가 무엇인지 설명하시오. 또, 실제 명령어의 정체는무엇인가?
#### 사용자가 리눅스 운영체제에 작업을 지시하기 위해 프롬프트에 입력하는 텍스 형태의 제어 지시어이다.


## 리눅스에서 가장 많이 사용되는 명령어 10개를 조사하고 설명하시오. 또 셸에서 실행하고 결과를 첨부하시오.
요청하신 **주요 리눅스 명령어 10개**를 마크다운 표 형태로 정리한 내용은 다음과 같습니다.

| 명령어 |  설명 |
| --- | --- |
| `ls` | 현재 디렉토리 내의 파일 및 폴더 목록 확인  |
| `pwd` | 현재 작업 중인 디렉토리의 경로 출력 |
| `cd` | 지정한 디렉토리로 위치 이동 |
| `mkdir` | 새로운 디렉토리 생성 | 
| `mv` | 파일/디렉토리 이동 또는 이름 변경 | 
| `cp` | 파일이나 디렉토리 복사 |
| `rm` | 파일 또는 디렉토리 삭제 (-r 옵션으로 디렉토리 삭제) | 
| `touch` | 빈 파일 생성 또는 기존 파일의 수정 시간 업데이트 |
| `ln` | 파일이나 디렉토리의 링크(심볼릭/하드 링크) 생성 | 
| `clear` | 터미널 화면에 출력된 이전 텍스트들을 깨끗이 비움 |

## 셸과 커널을 구분하여 자세히 설명하시오.
#### Kernel : 하드웨어와 프로세를 관리하는 역할이다.
#### Shell : 사용자와 커널을 이어주는 해석기(껍대기)이다. 사용자가 입력한 명령어를 커널이 처리하여 보낸 것을 텍스트로 표시한다.

## 프롬프트 문자열에서 문자 ~의 의미를 조사하라.
#### ~는 현재 로그인한 계정의 홈 디렉토리를 나타내는 약어이다.
#### 예: 계정이 Linux일 경우 ~는 /home/linux 경로를 의미하여, cd ~ 입력 시 단번에 홈 디렉토리로 이동한다.

## sh, bash, zsh 셸의 차이를 자세히 조사하시오.
#### sh : 가장 초기에 개발된 유닉스 기본 셸다. 매우 가볍고 단순하지만 자동완성이나 명령어 기능이 부족하다.
#### bash : sh를 바탕으로 기능을 확장한 니룩스 표준 셸이다.
#### zsh : bash의 기능을 모두 포함하면서 커스텀 기능을 추가한 셸이다.

## 셸 스크립트에 대하여 자세히 조사하시오.
#### 터미널에서 입력하던 셸 명렁어들을 하나의 파일로 적어둔 텍스트 기반 프로그램으로 조건문, 반복문, 변수 등으 ㄹ활용하여 반복저인 업우를 자동화하는 데 사용한다.

## Windows에서 사용하는 CLI방식의 셸의 종류를 조사하라.
#### PowerShell : .NET 프레임워크 기반의 객체 지향 셸이다. 텍스트만 처리하는 것이 아닌 객체 단위로 데이터를 처리하여 윈도우 시스템 관리 및 자동화를 담당한다.
#### WSL / BASH : 윈도우 에서 리눅스 환경을 구축하여 리눅스 BASH 셸을 사용할 수 있게 하는 레이어이다.
