# 실습과제 1
# 문제 01. 가상머신이란 무엇인가?
#### 컴퓨터 위에 소프트웨어로 만들어낸 가상화된 컴퓨터 시스템이다. <br><sub>**하나의 PC에 독립된 여러 대의 컴퓨터가 따로 돌아가는 것 처럼 구현함.**</sub>

# 문제 02. 가상머신을 사용하는 이유
#### 하나의 컴퓨터로 여러 운영체제를 동시에 분리한 상태로 사용할 수 있어, 하드웨어를 추가로 사지 않아도 다양한 환경에서 개발·테스트가 가능하다.

# 문제 03. WSL2의 장점
#### 실제 리눅스 커널을 가볍게 구현해서 부팅과 실행이 빠르고, 일반 가상머신처럼 큰 자원을 미리 할당할 필요가 없다. Windows와 파일 시스템·터미널 연동도 잘 돼서 개발 환경 구성이 편하다.

# 문제 05. CLI가 GUI보다 빠른 이유
#### GUI는 화면을 구성하고 갱신하는 데 시스템을 쓰지만, CLI는 텍스트 명령을 바로 해석·실행해서 자원 사용량이 적다. 

# 문제 06. 리눅스가 CLI를 주로 쓰는 이유
#### 서버나 원격 환경처럼 화면이 없는 곳이 많아 CLI가 기본 인터페이스이고, 자원을 적게 쓰기 떄문이다.

# 문제 07. 리눅스 명령어란 무엇이고 중요 5개 명령어를 조사하라. 실행결과를 첨부하라
#### 리눅스 운영체제를 CLI에서 제어하기 위해 입력하는 텍스트 지시어로, 파일 관리·시스템 설정·프로세스 제어 등을 수행한다.
#### 주요 명령어 5개

**1. `ls`** — 현재 디렉터리의 파일과 폴더 목록을 보여준다.

**2. `cd`** — 다른 디렉터리로 이동한다.

**3. `pwd`** — 현재 위치한 디렉터리의 전체 경로를 출력한다.

**4. `mkdir`** — 새 디렉터리(폴더)를 생성한다.

**5. `cd ..`** — 치면 상위(부모) 디렉터리로 나간다. <br><br>
