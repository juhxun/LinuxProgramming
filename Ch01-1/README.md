# Ch1-1 실습과제 1
# 문제01. UNIX 운영체제에 대하여 조사하시오.
※ 유닉스(UNIX)는 1969년 ATT&벨 연구소에서 C언어로 개발된 최초의 운영체제로 **대형 컴퓨터용 다중 사용자(Multi-user) 및 다중작업(Multi-tasking) 운영체제이다.**

### UNIX의 특징
- **이식성** : 90% 이상이 C 언어로 작성되어, 다양한 컴퓨터 시스템 간 이식이 용이하다.
- **다중 사용자 & 작업** : 여러 사용자가 동시에 시스템에 접속하여 사용할 수 있으며, 한 사용자가 여러 프로세스를 동시에 실행할 수 있다.
- **계층적 파일 시스템** : 트리 구조의 파일 시스템으로, 파일과 디렉터리를 효율적으로 관리한다.

### UNIX의 기본 구조
- **Kernel**: 프로세스 관리, 메모리 관리, 파일 시스템 관리, 입출력 제어 등 하드웨어 자원을 직접 제어한다.
- **Shell**: 사용자의 명령어를 해석하여 커널에 전달하고 결과를 출력해 주는 인터페이스이다.
- **유틸리티/응용 프로그램**: 사용자 편의를 위해 제공되는 다양한 명령어 및 개발 도구(vi, grep, awk, gcc 등)가 있다.
  
# 문제02. Linux, Windows, macOS 를 비교 설명하시오.
### 1. Linux
- 소스코드가 공개된 오픈소스 OS이며, 터니멀 환경이 매우 잘 발달해 있다. (모바일 및 임베디드 시스템에서 주로 사용된다.)
### 2. Windows
- 직관적인 GUI 기반 운영체제이다. (일반 사용자가 많이 사용한다.)
### 3. macOS
- Apple 전용 운영체제로 Unix 기반 OS이다.

# 문제03. 우분투(Ubuntu) 리눅스에 대하여 조사하시오.
### Ubuntu의 특징
- **좋은 편의성** : 무료로 설치가 쉽고, 기본 환경이 작관적이어서 일반 PC OS로 사용하기 좋으며, 정기적인 업데이트와 LTS 버전은 기본 5년간 보안 업데이트를 보장 한다. 
- **!!** : 데비안의 APT 패키지 관리를 이어받아서 수많은 오픈소스 소프트웨어를 쉽게 설치 및 관리할 수 있다!

### Ubuntu의 활용 분야
- 주요 클라우드 환경에서 가장 기본적인 리눅스 OS 중 하나이며, TensorFlow, PyTorch 등 주요 머신러닝 프레임워크와의 호환성이 뛰어나다.

- 오픈소스 OS로 개발 비용을 줄일수 있고, 커널을 자유롭게 다듬을 수 있어 경량화가 쉽다.
