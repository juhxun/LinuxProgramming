# 실습 과제 2

#### 현재 작업 디렉터리에서 루트 디렉터리로 이동하는 절대경로를 이용하는 명령어는?
- cd /
#### 현재 작업 디렉터리에서 루트 디렉터리로 이동하는 상대경로를 이용하는 명령어는?
- 현재 위치에서 루트까지 만큼 ..를 이어서 입력(ex:/1/2/3에 있다면 cd ../../..)

#### /usr/lib/gcc/x86_64-linux-gnu 디렉터리로 이동하는 절대경로를 이용하는 명령어는? 디렉터리 입력시도 자동완성 기능 이용할 것
- cd /usr/lib/gcc/x86_64-linux-gnu
#### /usr/lib/gcc/x86_64-linux-gnu 디렉터리로 이동하는 상대경로를 이용하는 명령어는? 디렉터리 입력시도 자동완성 기능 이용할 것
- ../../usr/lib/gcc/x86_64-linux-gnu
