# 실습 과제 1

#### 디렉터리
- 파일들을 계층으로 정리해서 보관하는 공간으로, 다른 운영체제의 "폴더"와 같은 개념이다.
#### 서브 디렉터리
- 특정 디렉터리 안에 속해 있는 하위 디렉터리를 말한다.
#### 작업 디렉터리
- 현재 사용자가 명령을 실행하고 있는 위치의 디렉터리(현재 디렉터리)를 의미한다.
#### 홈 디렉터리
- 사용자가 로그인했을 때 기본적으로 위치하게 되는, 그 사용자 전용의 디렉터리이다.
#### ~
- 현재 사용자의 홈 디렉터리를 가리키는 기호이다.
#### .
- 현재 작업 디렉터리 자기 자신을 가리키는 기호이다.
#### ..
- 현재 디렉터리의 상위(부모) 디렉터리를 가리키는 기호이다.
#### /
- 최상위 디렉터리(루트)를 나타내며, 경로 상에서 디렉터리 간의 구분자로 쓰인다
#### 상대 경로
- 현재 작업 디렉터리부터 목표 디렉터리 까지의 경로이다.
#### 절대 경로
- 루트(/)부터 시작해서 목표 위치까지 전체를 다 표시한 경로이다.
