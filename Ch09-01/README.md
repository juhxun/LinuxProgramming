# 실습 과제3
#### 리눅스에서 관리자 권한이 필요한 경우에 대하여 조사하라.
- 시스템 전체에 영향을 주는 파일을 작업 할 때 필요하며, 일반 사용자에게 퍼미션이 없는 파일을 읽거나, 다른 사용자가 소유한 파일의 퍼미션·소유자를 바꿀 때 필요하다.
#### 파일 퍼미션과 디렉터리 퍼미션의 의미의 차이점을 비교 설명하라.
- 파일에서 r, w, x는 각각 파일 내용 읽기, 내용 수정, 파일 실행을 의미하며, 디렉터리에서 r은 안의 파일 목록 보기(ls), w는 안에 파일 생성·삭제, x는 cd로 그 디렉터리에 이동하는 것을 의미한다.
#### Su명령어와 sudo 명령어의 차이를 설명하라.
- su는 슈퍼 사용자로 전환하는 명령어로, exit를 하기 전까지 계속 슈퍼 사용자 상태이다.
- sudo는 명령어 하나만 슈퍼 사용자 권한으로 실행하고 바로 일반 사용자로 돌아오며, 현재 로그인한 사용자의 암호를 입력한다.
